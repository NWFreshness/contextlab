# Error Codes Reference

This document lists all system error codes and their meanings.

## Checkout Errors

| Code | Meaning |
|------|---------|
| E-1001 | Payment declined - insufficient funds |
| E-1002 | Card expired |
| E-1003 | Invalid billing address |

## Inventory Errors

| Code | Meaning |
|------|---------|
| E-4471 | Inventory reservation expired |
| E-4472 | Item no longer available |
| E-4473 | Quantity exceeds available stock |

## Account Errors

| Code | Meaning |
|------|---------|
| E-5001 | Session timeout |
| E-5002 | Invalid authentication token |
| E-5003 | Account suspended |

## Shipping Errors

| Code | Meaning |
|------|---------|
| E-6001 | Invalid shipping address |
| E-6002 | Address outside delivery area |
| E-6003 | Package too large for carrier |

For support, contact help@example.com with your error code.
